# SaunaMath

The honest math of building a home sauna: room volume with glass and cold-wall penalties, heater kilowatts, stone weight, bench capacity, heat-up time, and per-session electricity cost.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - four cards (room, heater, bench, cost) with size presets.

Part of the App Factory: https://github.com/iLanis-agent/app-factory
